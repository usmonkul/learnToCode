# Yaratuvchi.uz

A programming tutorial platform where students read courses, practice in Arena, and browse working practice projects. This glossary pins down the words used when designing and talking about course content.

## Language

### Courses

**Course**:
An ordered set of lessons on one technology, aimed at one level of student.
_Avoid_: Track, module, class

**Course pair**:
Two courses on the same technology, a fundamentals course and its `-advanced` sequel, where the sequel assumes the student finished the first (e.g. `react` → `react-advanced`).
_Avoid_: Part 1/Part 2, volume

**Section**:
A consecutive group of lessons inside a course that together cover one theme, shown as a group in the sidebar.
_Avoid_: Chapter, unit, module

**Lesson**:
One page of a course that teaches one concept and stands on its own given the lessons before it.
_Avoid_: Article, page, tutorial

**Section project**:
The last lesson of a section, a guided build that uses only what that section and earlier sections taught.
_Avoid_: Mini-project, capstone, homework

**Stretch task**:
An extra task at the end of a section project for the student to do alone, deliberately given without a solution.
_Avoid_: Bonus, homework, extra exercise

**Course project**:
The last section project of a course, which uses most of what the whole course taught.
_Avoid_: Final project, capstone
